# Crunch FZ v1.0.4

Crunch FZ generates real wordlists directly to microSD without accumulating the complete output. It supports native character sets, patterns, bounded calculations, cancellation, and optional genuine Crunch operation through a Raspberry Pi or other Linux computer over UART.

This maintenance release refreshes application/companion version metadata and is clean-built and validated for Flipper target f7/API 87.1.

Download `crunch_fz.fap` and copy it to `/ext/apps/Tools/` on the Flipper.
